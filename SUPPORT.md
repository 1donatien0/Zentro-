# Support

Need help running **Zentro**, found a bug, or want to suggest an improvement? Here is where to go.

---

## Before Opening a New Issue

Please search [existing GitHub Issues](https://github.com/Ayaan-20-11/Zentro-/issues) first to check whether your question, bug, or feature idea has already been raised or answered.

> **Note:** GitHub Discussions are not currently enabled on this repository. Please use **GitHub Issues** for bug reports, feature requests, documentation improvements, and general project questions.

---

## Where to Go

- **Report a Bug:**
  Open an issue using the **Bug Report** template at [`https://github.com/Ayaan-20-11/Zentro-/issues/new/choose`](https://github.com/Ayaan-20-11/Zentro-/issues/new/choose).
- **Suggest a Feature or Improvement:**
  Open an issue using the **Feature Request** template at [`https://github.com/Ayaan-20-11/Zentro-/issues/new/choose`](https://github.com/Ayaan-20-11/Zentro-/issues/new/choose).
- **Documentation Fixes or Gaps:**
  Open an issue using the **Documentation** template at [`https://github.com/Ayaan-20-11/Zentro-/issues/new/choose`](https://github.com/Ayaan-20-11/Zentro-/issues/new/choose).
- **General Questions:**
  Open a new issue at [`https://github.com/Ayaan-20-11/Zentro-/issues/new/choose`](https://github.com/Ayaan-20-11/Zentro-/issues/new/choose) describing your question clearly.
- **Security Vulnerabilities:**
  Do **not** open a public issue. Follow [`SECURITY.md`](SECURITY.md).
- **Code of Conduct Concerns:**
  Follow the private reporting guidance in [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

## How to Write a Helpful Bug Report

To help maintainers and contributors reproduce and fix issues faster, please include:

1. **Page and flow:** Which file/page you were on (`index.html`, `home.html`, `checkout.html`, or `success.html`) and how you ran it (for example, Live Server on port `5501` or `python3 -m http.server`).
2. **Exact steps to reproduce:** Clear, numbered steps starting from page load.
3. **Expected vs. actual behavior:** What you expected to happen and what actually happened.
4. **Environment:** Your operating system, browser name/version, and screen width (desktop vs. mobile).
5. **Console or visual evidence:** Any errors shown in browser DevTools Console, plus screenshots if it is a UI/layout bug.

For public questions, bug reports, and feature discussions, please use [GitHub Issues](https://github.com/Ayaan-20-11/Zentro-/issues) so other contributors can benefit from the discussion.
